# 🚫 AI 자동 배포 금지 및 엄격한 보고 지침 (v2.0)

본 문서는 AI(Antigravity)의 독단적인 배포로 인한 운영 환경 사고를 방지하기 위해 작성된 **최상위 지침**입니다.

## 🔴 절대 금지 사항 (Strict Prohibitions)
- **개별 건별 승인 필수**: 이전에 "배포해"라고 했다고 해서 현재의 작업도 승인된 것으로 간주하지 마십시오. 모든 배포는 **매번 개별적인 확인**이 필요합니다.
- **임의 명령어 실행 금지**: `vercel --prod`, `git push` 등 운영 서버에 영향을 주는 명령어를 사용자 승인 없이 실행하는 것은 **중대한 지침 위반**입니다.
- **통보 후 실행 금지**: "배포하겠습니다"라고 말하고 바로 실행하지 마십시오. 반드시 답신을 기다려야 합니다.

## ⚙️ 로직 구현 및 수정 원칙 (Logic Rules)
- **스킬 파일 필독**: 오드(행동력), 티켓, 처치 횟수 등 게임 엔진 로직과 관련된 모든 작업(툴, 웹 공통) 시 반드시 [aion2-mechanics](file:///c:/Users/admin/Documents/KHW_AI/AION2_Guild_Raid/aion2-od-helper/skills/aion2-mechanics/SKILL.md) 스킬 파일을 먼저 읽고 숙지해야 합니다.
- **추측 금지**: 해당 스킬 파일에 정의되지 않은 새로운 로직이나 수치가 필요한 경우, AI가 임의로 판단하지 말고 **반드시 사용자에게 상세히 물어보고 승인**을 받은 뒤 구현하십시오.
- **설명 의무**: 로직에 대해 설명할 때는 스킬 파일의 용어와 수치를 그대로 사용하여 토시 하나 틀리지 않게 정확히 전달해야 합니다.

## 🔒 시스템적 잠금장치 (System Lock)
- **deploy-lock.json**: 프로젝트 루트의 이 파일은 AI의 배포 명령 제안을 원천 봉쇄하는 '안전핀'입니다.
- AI는 배포 관련 명령어를 생각하기 전 반드시 이 파일을 먼저 읽어야 하며, 상태가 `"LOCKED"`인 경우 사용자로부터 텍스트 승인을 받았더라도 **명령어 도구를 꺼낼 수 없습니다.**
- 잠금을 해제하려면 사용자가 직접 이 파일을 `"UNLOCKED"`로 수정해야 합니다.

## ✅ 올바른 보고 및 배포 절차
1. **작업 완료**: 코드 수정 및 로컬 빌드(`npm run build`) 성공 확인.
2. **요약 보고**: 변경된 사항을 사용자에게 명확히 보고.
3. **배포 의사 타진**: "배포 준비가 되었습니다. **지금 이 변경 사항을 운영 서버에 배포할까요?**"라고 질문.
4. **승인 대기**: 사용자의 명시적인 승인 답변이 올 때까지 대기.
5. **잠금 확인**: 사용자 승인 후, [deploy-lock.json](file:///c:/Users/admin/Documents/KHW_AI/AION2_Guild_Raid/aion2-od-helper/deploy-lock.json) 파일이 `"UNLOCKED"` 상태인지 확인.
6. **최종 실행**: 모든 조건이 충족되었을 때만 배포 명령어를 제안하거나 실행.

## 📢 AI 행동 강령
- AI는 배포 권한이 없음을 명심하십시오. 배포 버튼을 누르는 것은 오직 **사용자**입니다.
- 이 규칙은 어떠한 긴급 상황에서도 예외 없이 적용됩니다.
