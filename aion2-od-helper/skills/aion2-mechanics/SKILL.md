# 🐣 AION2 숙제 관리 도우미: 핵심 엔진 및 티켓 로직 명세 (v3.0)

본 명세는 `lib/engine.ts`에 구현된 아이온2 게임 내 자원 회복 및 소모 로직을 정의합니다. AI는 이 수치를 바탕으로 상태를 계산하며, 임의로 변경하지 않습니다.

## 1. 오드 (Ode) 시스템
*   **최대 보유량**: 멤버십 적용 시 **840**, 미적용 시 **540**.
*   **회복 방식**: 실시간(분당/시간당) 회복이 아닌, **3시간 단위 게이트 방식**으로 회복됩니다.
    *   **회복 시각 (Gate)**: 02, 05, 08, 11, 14, 17, 20, 23시 (KST 기준).
    *   **회복 수치**: 게이트 통과 시마다 멤버십 **15**, 미적용 **10** 회복.
*   **소모 수치**: 모든 원정/초월/성역 실행 시 멤버십 **80**, 미적용 **40** 차감.
*   **특이사항**: 추가 오드(Ode Extra)는 자동으로 회복되지 않으며, 소모 시 기본 오드부터 먼저 차감됩니다. (최대 2000 보유 가능)

## 2. 원정 (Expedition) 로직
*   **기본 티켓**: 12시간마다 **1장** 회복 (05시, 17시 게이트). 최대 **14장**까지 누적.
*   **주간 보상 한도 (보상 패널티)**: 캐릭터당 주간 기본 **35회**. (매주 수요일 05시 초기화)
*   **소모**: 실행 시 '기본 티켓' 1장과 '처치 횟수' 1회를 동시 소모.
*   **보존**: 주간 초기화 시 **'추가 티켓' 및 '추가 처치 횟수'는 초기화되지 않고 유지**됩니다.

## 3. 초월 (Transcendence) 로직
*   **기본 티켓**: 24시간마다 **2장** 회복 (05시 게이트). 최대 **7장**까지 누적.
*   **주간 보상 한도 (보상 패널티)**: 캐릭터당 주간 기본 **28회**. (매주 수요일 05시 초기화)
*   **소모**: 실행 시 '기본 티켓' 1장과 '처치 횟수' 1회를 동시 소모.
*   **보존**: 주간 초기화 시 추가 자원은 유지됩니다.

## 4. 성역 (Sanctuary) 로직
*   **입장 티켓 (입장 횟수)**: 매주 **수요일 05시**에 **4장** 충전. 최대 **4장**까지 누적 가능.
*   **주간 보상 한도 (보상 횟수)**: 캐릭터당 주간 기본 **2회**. (매주 수요일 05시 초기화)
*   **소모**: 실행 시 '입장 횟수' 1회와 '보상 횟수' 1회를 동시 소모.
*   **보존**: 주간 초기화 시 사용자가 충전한 추가 입장/보상 횟수는 유지됩니다.

## 5. 체크리스트 및 초기화 규칙
모든 초기화는 KST 05:00(매일) 또는 수요일 05:00(주간)에 수행됩니다.

*   **계정 단위 (Account-wide / 동기화)**:
    *   **사명 (Mission)**: **매일 05시** 초기화. 계정 내 모든 캐릭터가 상태를 공유합니다.
    *   **일일 던전 (Daily Dungeon)**: **매주 수요일 05시** 초기화. 계정 내 모든 캐릭터가 상태를 공유합니다.
    *   **슈고/침공 티켓**: 각각 24시간마다 2장/1장 회복 (05시).
*   **캐릭터 단위 (Individual)**:
    *   **회랑 (Corridor)**: **매주 수요일 및 토요일 오후 22:00** 초기화.
    *   **각성 (Awakening)**: **매주 수요일 05시** 초기화.
    *   **악몽 (Nightmare)**: 매일 05시, 완료 카운트에서 **2씩 자동 차감** (기회 생성). 웹 대시보드에서는 체크박스로 표시됩니다.
