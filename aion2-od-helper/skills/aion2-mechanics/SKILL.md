# 🐣 AION2 숙제 관리 도우미: 핵심 엔진 및 티켓 로직 명세 (v2.1)

본 명세는 `lib/engine.ts`에 구현된 아이온2 게임 내 자원 회복 및 소모 로직을 정의합니다. AI는 이 수치를 바탕으로 상태를 계산하며, 임의로 변경하지 않습니다.

## 1. 오드 (Ode) 시스템
*   **최대 보유량**: 멤버십 적용 시 **840**, 미적용 시 **540**.
*   **회복 방식**: 실시간(분당/시간당) 회복이 아닌, **3시간 단위 게이트 방식**으로 회복됩니다.
    *   **회복 시각 (Gate)**: 02, 05, 08, 11, 14, 17, 20, 23시 (KST 기준).
    *   **회복 수치**: 게이트 통과 시마다 멤버십 **15**, 미적용 **10** 회복.
*   **소모 수치**: 모든 원정/초월/성역 실행 시 멤버십 **80**, 미적용 **40** 차감.
*   **특이사항**: 추가 오드(Ode Extra)는 자동으로 회복되지 않으며, 소모 시 기본 오드부터 먼저 차감됩니다.

## 2. 원정 (Expedition) 로직
*   **기본 티켓**: 12시간마다 **1장** 회복 (05시, 17시 게이트). 최대 **14장**까지 누적.
*   **주간 처치 한도**: 캐릭터당 주간 최대 **35회**. (리셋 시 35회로 충전)
*   **소모**: 실행 시 '기본 티켓' 1장과 '처치 횟수' 1회를 동시 소모 (기본 부족 시 추가 티켓 사용).

## 3. 초월 (Transcendence) 로직
*   **기본 티켓**: 24시간마다 **2장** 회복 (05시 게이트). 최대 **7장**까지 누적.
*   **주간 처치 한도**: 캐릭터당 주간 최대 **28회**. (리셋 시 28회로 충전)
*   **소모**: 실행 시 '기본 티켓' 1장과 '처치 횟수' 1회를 동시 소모.

## 4. 성역 (Sanctuary) 로직 (수정됨)
*   **기본 티켓**: 매주 **수요일 05시**에 **4장** 회복. 최대 **4장**까지 누적 가능.
*   **주간 처치 한도**: 캐릭터당 주간 최대 **2회**. (매주 수요일 05시 초기화 시 2회로 충전)
*   **소모**: 실행 시 '기본 티켓' 1장과 '처치 횟수' 1회를 동시 소모.

## 5. 계정 단위 자원 (Account-wide)
*   **슈고 (Shugo)**: 24시간마다 **2장** 회복 (05시 게이트). 최대 **14장**.
*   **침공 (Invasion)**: 24시간마다 **1장** 회복 (05시 게이트). 최대 **7장**.
